# Multica - Managed Agents Platform

Multica is a platform for turning coding agents into teammates and compounding reusable skills.

## Quick Start

1. Install Multica CLI
2. Configure agent teams
3. Use Multica to manage agent workflows

## Features

- Multi-agent orchestration
- Reusable skill compounding
- Team-based agent management
- Integration with Claude Code, Codex, Cursor, OpenCode
