# 来源

- 项目：https://github.com/open-webui/open-webui（v0.13.0，157k⭐）
- 安装日期：2026-11-04
- 安装方式：`uv tool install --python 3.12 open-webui`（官方要求 Python >=3.11,<3.13，本机默认 3.13，uv 自动拉 3.12 独立环境）
- 启动：`open-webui serve --port 8080`；自动探测本机 Ollama（127.0.0.1:11434）
- 与 Odysseus 关系：功能重叠（都是本地模型聊天 UI），Open WebUI 胜在社区生态、知识库/RAG 更成熟、支持 OpenAI 兼容端点更多；两者共存
