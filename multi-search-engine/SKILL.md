## 常见问题FAQ

### Q1: 如何在Multi Search Engine中搜索特定网站的内容？
A: 使用`site:`前缀加上网站域名，例如`site:github.com+react`，可以在特定网站内搜索相关内容。

### Q2: Multi Search Engine支持哪些国际搜索引擎？
A: Multi Search Engine支持9个全球搜索引擎，包括Google、Bing、DuckDuckGo等。

### Q3: 如何使用Multi Search Engine进行时间范围搜索？
A: 在Google搜索中，可以使用`tbs=qdr:`参数来指定时间范围，例如`tbs=qdr:w`表示过去一周的搜索结果。

### Q4: Multi Search Engine如何处理重复的搜索结果？
A: Multi Search Engine会自动聚合和去重搜索结果，确保每个结果只显示一次。

### Q5: 如果搜索结果中没有找到满意的内容，应该怎么办？
A: 可以尝试使用不同的关键词或组合关键词，或者调整搜索条件，例如使用不同的搜索引擎或时间范围。

## 错误恢复
针对搜索引擎使用中可能遇到的常见问题,提供以下排查方案:

| 错误类型 | 原因分析 | 解决方案 |
|---------|---------|---------|
| API认证失败(401) | API密钥错误或过期 | 检查密钥配置,重新生成token |
| 接口限流(429) | 请求频率超出限制 | 降低调用频率,启用重试退避策略 |
| 响应超时(504) | 网络延迟或服务端负载过高 | 增加超时阈值,检查网络连接 |
| 文件不存在 | 路径错误或文件未创建 | 检查路径拼写,确认文件已生成 |
| 文件格式不支持 | 扩展名不在支持列表中 | 转换为支持的格式后重试 |
| 权限不足 | 当前用户无读写权限 | 检查文件权限,以管理员身份运行 |
| 命令执行失败 | 参数错误或环境依赖缺失 | 检查命令语法,确认依赖已安装 |
| 进程超时 | 命令执行时间过长 | 增加超时设置,优化命令参数 |
| 网络连接失败 | DNS解析失败或防火墙拦截 | 检查网络配置,确认代理设置 |
